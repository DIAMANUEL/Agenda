# Calendario de clase

Proyecto estático para publicar en Netlify y usar Supabase como base de datos.

## Actualización

Sustituye los archivos del repositorio por los de esta carpeta. Esta versión no incluye los iconos de la PWA para conservar los que ya tienes: deja tu carpeta `icons/` existente en el repositorio.

No es necesario ejecutar SQL ni cambiar la base de datos para esta actualización.

## Configuración

Conserva tu `config.js` con la URL y la publishable key de tu proyecto Supabase.
